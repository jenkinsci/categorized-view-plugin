Interpret slashes in category names as group separators. For example, the naming rule FootLocker/FLX User creates an FLX User subgroup inside FootLocker. Capture substitutions also work, for example $1/$2. Each group can be expanded or collapsed independently, and parent summaries include jobs in all descendant groups. Names with empty segments (such as A//B) remain literal names. Disabled by default to preserve existing category names.
