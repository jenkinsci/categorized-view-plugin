If checked, the item's full name (the slash-separated path, e.g. folder/multibranchJob/PROJ-123) will be used to categorize, instead of the job name. This is useful for grouping multibranch pipeline branches (which otherwise only expose their branch name, e.g. PROJ-123) by their parent job.

If both "Categorize by display name?" and this option are checked, the full name takes precedence.
